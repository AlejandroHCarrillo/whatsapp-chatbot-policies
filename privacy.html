Política de privacidad

Esta página describe una aplicación de prueba del chatbot de WhatsApp. No es la política de privacidad de PepsiCo ni de ninguna campaña comercial.

Última actualización: 7 de octubre de 2026.

Qué datos se usan

Cuando escribes al número de prueba, la aplicación recibe de WhatsApp Cloud API tu identificador de WhatsApp, el nombre de perfil que envía Meta y el texto de los mensajes, para poder responder en esa misma conversación.

Para qué se usan

Solo para contestar el menú de demostración, validar códigos de prueba y guardar el hilo de la conversación mientras dura la prueba. No se venden ni se usan para publicidad.

Dónde se guardan

En una base local del entorno de desarrollo que ejecuta la prueba. El acceso está limitado a quien opera ese entorno.

Cuánto tiempo

Durante la prueba. Al cerrarla, los mensajes guardados en ese entorno se pueden borrar.

WhatsApp

El envío y la recepción pasan por WhatsApp Cloud API de Meta. El uso de WhatsApp también está sujeto a las políticas de Meta.
